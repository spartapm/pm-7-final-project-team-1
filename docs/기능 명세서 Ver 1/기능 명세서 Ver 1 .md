# 기능 명세서 Ver.1

# 1. 핵심 기능 정의

- **기능명** : **개인 맞춤 랭킹**
- **기능 한 줄 설명**: 사용자의 피부 타입·피부 고민에 따라 달라지는 **개인화된 스킨케어 랭킹**을 제공한다.
- **이 기능을 핵심으로 선정한 이유**
    
    <aside>
    
    [페르소나 : 김소은]은 수많은 스킨케어 제품 중 자신의 피부 타입·고민·민감도에 맞는 제품을 찾기 위해 유사 조건 사용자의 후기와 성분 정보를 일일이 비교해야 한다. **리뷰와 성분표 모두 정보는 있는데 경험이 유사한 사용자의 신뢰할 수 있는 후기와 성분의 역할·주의사항을 선별하기는 어려워, 여러 채널을 반복 탐색하고도 구매 후보를 좁히는 데 어려움을 겪는다.**
    
    **사용자의 피부 타입·피부 고민·민감도를 기준으로 유사 사용자 그룹을 구성하고, 해당 그룹의 제품 랭킹을 제공**하면 [김소은]은 여러 정보들(리뷰, 성분, 등)을 반복해서 탐색하지 않고도 **자신에게 맞는 제품 후보를 좁힐 수 있을 것이라 판단**해 선정했다.
    
    </aside>

    **4) 세션 정책**
    
    - 인증 성공 만 할 경우에는 세션 발급 X, 3-3의 약관동의까지 완료 후 세션 발급
    
    **5) 예외처리**
    
    - 소셜 인증 실패/취소 시 화면 복귀(별도 에러 노출 없음)

### 3-3. 약관 동의 바텀 시트

<aside>

**1) 바텀시트 구성**

- 약관 전체 동의 체크박스(해당 체크박스 클릭 시, 하단 4가지 항목 자동 체크 처리)
- 4가지 항목에 대한 체크박스 모두 필수 선택
    - 서비스 이용약관 동의
    - 개인정보 수집 및 이용 동의
    - 피부 정보 수집/이용 동의
    - 만 14세 이상이에요(만 14세 미만은 가입이 제한됨)
- 기본값 : 미동의

**2) 버튼 활성화 조건**

- 4가지 항목 모두 선택 시에만 "동의하고 가입하기" 버튼 활성화

**3) 동의 완료 시 동작**

- "동의하고 가입하기" 버튼 클릭 시, 각 서비스 OAuth 인증 화면으로 이동 → 인증 성공 시 계정 생성(닉네임 자동 생성) → "회원가입이 완료되었습니다" 토스트 → 홈 이동
- (소셜 로그인으로 진입한 신규 계정의 경우) 동의 완료 후 '동의하고 가입하기' 클릭 시에만 계정 생성 → "회원가입이 완료되었습니다" 토스트 → 홈 이동

**4) 세션 정책**

- 인증 성공 및 약관 동의 후 발급되는 세션은 사용자 선택과 무관하게 항상 30일간 유지(자동 로그인 필수 적용, 별도 선택 UI 없음)

**5) 이탈 시 예외처리**

- 신규 계정인데 바텀시트에서 동의를 완료하지 않고 이탈하는 경우, 계정은 생성되지 않음 → 로그인/회원가입 화면으로 복귀(재시도 시 소셜 인증부터 다시 진행)

**이용 약관 및 개인정보 처리방침**: [이용약관 및 개인정보 처리방침 Ver.0](https://app.notion.com/p/Ver-0-3cf2dc3ef51480a0a01ff7a59f94040a?pvs=21) 

</aside>

### 3-4. 온보딩(피부 프로필) : 피부 타입 & 고민 선택

<aside>

**요소·기능명**: 온보딩 → 피부 프로필 설문 → 피부 타입/고민 정보 수집

**1) 진입 시점**

- 회원가입/로그인 직후 최초 1회 자동 노출
- 피부 타입 정보 입력시 홈으로 이동
- 이후 마이페이지 → 피부 프로필에서 재진입해 언제든 수정 가능

**2) “X”버튼**

- 화면 좌측 상단에 위치
- 화면 좌상단 X 버튼 탭 시 3-5. 온보딩 이탈 방지 팝업 노출

**2) 입력 항목 및 선택 방식**

- 피부 타입: 단일 선택, 필수
- 피부 고민: 다중 선택, 필수

**3) 버튼 동작 `선택하고 추천받기` (CTA)**

- 최소 1개 필수값(피부 타입) 미입력 시 비활성화(회색 #DAD7D7) 처리
- 입력 완료 시 활성화(핑크색 #C85C78)로 전환

**4) 저장 시점**

- 각 항목 선택 즉시 로컬 상태(state)에 반영
- 최종 **`선택하고 추천받기`** 탭 시점에 서버로 일괄 전송
- 스킵 시에는 서버 전송 없음

**5) 후속 연동 (수정)**

- 설문에서 선택한 피부 타입, 피부 고민 값(=`skin_type`)이 유저의 기본 설정값(default filter)으로 저장됨.
홈 화면 랭킹 탭 진입 시, 별도 필터 조작 없이 해당 유저의 `skin_type`을 기준으로 자동 필터링된 제품 랭킹이 기본 노출됨
- 유저가 랭킹 탭 내에서 다른 피부타입 탭을 수동 선택하면 그 세션 동안만 임시로 필터 변경(설문값 자체는 유지, 덮어쓰지 않음)
</aside>

### 3-5. 온보딩 이탈 방지 팝업

<aside>

**1) 팝업 구성**

- 안내 문구 : "잠깐만요! 정보를 입력해야 서비스를 이용할 수 있어요"
- 버튼 A(좌측/보조): `앱 종료`
- 버튼 B(우측/주요, 강조색): `계속 입력할게요`

**2) 버튼 동작**

- 버튼 A(앱 종료) 클릭 시 : 앱 종료
- 버튼 B(계속 입력할게요) 클릭 시 : 팝업 닫힘
    - 온보딩 화면(피부타입/고민 선택 화면)으로 복귀
    - 기존 입력값(선택했던 피부타입 등)은 유지된 상태 그대로 화면 표시

**3) 팝업 외부 영역**

- 딤 배경(팝업 바깥) 탭 시 → 팝업 닫히지 않음(반드시 버튼 선택 필요)
</aside>

### 3-6. 개인 맞춤형 랭킹

- **화면 기능 개요**
    
    
    | 항목 | 내용 |
    | --- | --- |
    | 기능명 | 개인 맞춤형 스킨케어 랭킹 |
    | 기능 목적 | 사용자가 전체 인기 제품을 직접 비교하지 않고, 자신의 피부 조건에 적합한 제품 후보를 빠르게 확인할 수 있도록 함 |
    | 이용 조건 | 로그인 후 피부 타입과 피부 고민 설정을 완료한 사용자 |
    | 동작 방식 | 사용자의 피부 타입·피부 고민과 제품의 성분·적합 정보를 비교하여 관련도가 높은 제품부터 순서대로 노출 |
    | 랭킹 기준 | 초기에는 피부 타입 및 피부 고민과 관련된 성분 정보를 기준으로 정렬
    리뷰가 쌓인 이후에는 유사한 피부 조건을 가진 사용자 리뷰/찜 데이터 추가 반영 |
    | 노출 정보 | 순위, 제품 이미지, 브랜드명, 제품명, 평점 |
    | 사용자 액션 | 카테고리 변경, 제품 상세 페이지 이동 |
    | 정보 변경 | 사용자가 피부 타입이나 피부 고민을 수정하면 변경된 정보를 기준으로 랭킹 재생성 |
    | 갱신 기준 | 제품 정보 또는 리뷰 데이터가 변경되거나 사용자의 피부 프로필이 수정된 경우 갱신 |
- **기본 이용 플로우**
    
    > 개인 맞춤형 랭킹 진입 → 사용자 피부 프로필 불러오기 → 선택 카테고리 기준 제품 적합도 계산 → 적합도 순 노출 → 제품 선택 시 상세페이지 이동
    > 
- **상세 동작 : 개인 맞춤형 랭킹 기본 노출**
    
    <aside>
    
    - **랭킹 규칙**: [MVP 랭킹 규칙 Ver.1](https://app.notion.com/p/MVP-Ver-1-3cf2dc3ef51480048ec7ea32395db2a5?pvs=21)
    
    **1) 진입 시점**
    
    - 온보딩 완료 후 홈 진입 시 노출
    - 마이페이지에서 피부 프로필 수정 후 홈으로 돌아오면 갱신된 랭킹 노출(랭킹 규칙에 따름)
    
    **2) 기본 노출 기준**
    
    - 유저에게 저장된 `skin_type`를 기준으로 랭킹 조회(랭킹 규칙에 따름)
    - 별도 조작 없이 저장된 피부 타입이 기본 필터로 적용됨
    
    **3) 화면 구성**
    
    - **내 피부 타입 표기**
        - 저장된 `skin_type` 을 랭킹 상단에 기본 노출
    - **카테고리 버튼**
        - 크림, 스킨/토너, 클렌징 폼 분류
        - 기본값 : 크림 랭킹
        - 활성상태 : 텍스트/테두리 색상 `#C85C78` , 버튼배경 색상 `#FDEEF1`
        - 비활성상태 : 텍스트 색상 `#3A1F27`
    - **추천 근거 문구 태그**
        - “피부타입/피부 고민 기반 적합 성분 순위에 따른 안내” 텍스트 노출(`#B3A8AB`)
        - “`skin_type` 을 위한 크림” 텍스트 노출(`#3A1F27`)
        - ex> `skin_type` 이 복합성(피부 타입), 트러블/진정(피부고민) 일 경우
                ⇒ “복합성 · 트러블/진정을 위한 크림”으로 노출
    - **랭킹 목록**
        - 노출 정보 : 순위, 제품 이미지, 브랜드명, 제품명
        - 정렬 기준

- “연동된 소셜 계정 정” 텍스트 `#8A6B71`
- “탈퇴 시 유지되는 데이터” 텍스트 `#C85C78`
- “작성한 리뷰(닉네임 익명처리) + 찜 통계(개인 연결 정보 삭제) ” 텍스트 `#8A6B71`
- 모두 동의하고 탈퇴 희망합니다 (CTA)
    - 버튼색상 `#C85C78` , 텍스트 색상 `#FFFFFF`
    - 버튼 클릭 시 최종 탈퇴 처리

**2) 처리 방식**

- 사용자가 탈퇴를 요청하면 연동된 소셜 계정(구글/카카오) 연동을 해제하고 서비스 내 계정 데이터를 즉시 삭제
- 단, 리뷰 데이터의 경우에는 작성자 닉네임을 "탈퇴한 회원의 리뷰 입니다"로 변경하여 유지되며, 찜 데이터는 탈퇴 시 회원 개인과의 연결 정보는 삭제하되, 제품별 찜 수치는 랭킹 산정을 위한 통계자료로 비식별화하여 유지
- 팝업 내용 확인 후 탈퇴 의사 없을 경우 팝업창 뒷편의 딤드 화면 클릭 시 → 마이페이지로 이동
