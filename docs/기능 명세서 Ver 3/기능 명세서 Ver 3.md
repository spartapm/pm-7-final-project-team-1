# A. 핵심 기능 정의

- **기능명** : **개인 맞춤 랭킹**
- **기능 한 줄 설명**: 사용자의 피부 타입·피부 고민에 따라 달라지는 **개인화된 스킨케어 랭킹**을 제공한다.
- **이 기능을 핵심으로 선정한 이유**
    
    <aside>
    
    [페르소나 : 김소은]은 수많은 스킨케어 제품 중 자신의 피부 타입·고민·민감도에 맞는 제품을 찾기 위해 유사 조건 사용자의 후기와 성분 정보를 일일이 비교해야 한다. **리뷰와 성분표 모두 정보는 있는데 경험이 유사한 사용자의 신뢰할 수 있는 후기와 성분의 역할·주의사항을 선별하기는 어려워, 여러 채널을 반복 탐색하고도 구매 후보를 좁히는 데 어려움을 겪는다.**
    
    **사용자의 피부 타입·피부 고민·민감도를 기준으로 유사 사용자 그룹을 구성하고, 해당 그룹의 제품 랭킹을 제공**하면 [김소은]은 여러 정보들(리뷰, 성분, 등)을 반복해서 탐색하지 않고도 **자신에게 맞는 제품 후보를 좁힐 수 있을 것이라 판단**해 선정했다.
    
    </aside>

> 
>

# C. 데이터 처리

초기에는 브랜드 공식 홈페이지와 공식 판매처를 기준으로 제품 정보를 수기로 수집하고, 각 제품에 공식 출처 URL과 정보 확인일을 함께 저장한다. 등록 이후에는 주 1회 자동화 파이프라인을 통해 제품 페이지의 접근 여부와 제품명·용량·전성분·판매 상태 변경을 감지한다.

변경이 감지된 정보는 서비스에 즉시 반영하지 않고 운영자 검수 목록에 등록하며, 공식 출처 확인 후 승인된 정보만 반영한다. 전성분이나 주요 기능이 변경된 리뉴얼 제품은 기존 데이터를 수정하지 않고 별도의 제품 버전으로 관리한다. 단종 제품은 랭킹에서 제외하되 기존 리뷰와 제품 정보는 보존한다. (VION 서비스 규칙서 참고)

식약처 원료성분 및 사용제한 원료 데이터는 API를 통해 주기적으로 확인한다. 기능성화장품의 품목명과 책임판매업자 정보 등은 [식약처 기능성화장품 보고품목정보 API](https://www.data.go.kr/data/15095680/openapi.do?utm_source=chatgpt.com)와 대조한다.
