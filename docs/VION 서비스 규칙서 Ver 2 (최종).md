# 1. 피부 타입 선정 규칙

**피부 타입 판단 질문(8가지)**

| 질문 | 선택지 |
| --- | --- |
| **Q1. 세안 후 피부는 보통 어떤 느낌인가요?** | ① 많이 당기거나 건조하다 ② 편안하다 ③ 금방 유분이 느껴진다 |
| **Q2. 오후가 되면 얼굴의 유분은 어떤가요?** | ① 거의 없다 ② 이마·코 위주로 번들거린다 ③ 얼굴 전체가 번들거린다 |
| **Q3. 볼 부위는 평소 어떤 편인가요?** | ① 건조하거나 거칠다 ② 특별히 건조하거나 번들거리지 않는다 ③ 유분이 많은 편이다 |
| **Q4. 이마와 코(T존)는 어떤 편인가요?** | ① 건조한 편이다 ② 적당하다 ③ 유분이 많은 편이다 |
| **Q5. 피부가 번들거리는데도 속이 당기는 느낌이 있나요?** | ① 자주 있다 ② 가끔 있다 ③ 거의 없다 |
| **Q6. 피부에 각질이나 거친 느낌이 자주 생기나요?** | ① 자주 있다 ② 가끔 있다 ③ 거의 없다 |
| **Q7. 보습 제품을 바른 뒤에도 피부가 당기거나 금방 번들거리나요?** | ① 그래도 당긴다 ② 비교적 편안하다 ③ 금방 번들거린다 |
| **Q8. 이마·코와 볼의 피부 상태 차이가 큰가요?** | ① 차이가 크다 ② 약간 다르다 ③ 거의 비슷하다 |
- `O = 유분 점수(Oiliness)`
- `D = 건조 점수(Dryness)`
- `R = 부위 차이 점수(Region difference)`
- `H = 유분 + 속건조 동시 발생 점수(Hydration imbalance)`

**점수표**

| 우선순위 | 피부 타입 | 판정 조건 | 의미 |
| --- | --- | --- | --- |
| 1 | **복합성** | `R >= 3` | T존과 볼 등 부위별 차이가 뚜렷함 |
| 2 | **수부지** | `R < 3 AND H >= 2 AND D >= 4 AND O >= 4` | 얼굴 전체적으로 유분이 있으면서 속건조도 강함 |
| 3 | **건성** | `R < 3 AND D >= 4 AND D - O >= 2` | 유분보다 건조 특성이 뚜렷하게 높음 |
| 4 | **지성** | `R < 3 AND O >= 4 AND O - D >= 2` | 건조보다 유분 특성이 뚜렷하게 높음 |
| 5 | **중성** | **위 조건에 모두 해당하지 않을 경우** | 건조·유분 어느 한쪽으로 크게 치우치지 않음 |

**타입 평가 방법**

| 변수 | 의미 | 최대 점수 |
| --- | --- | --- |
| **D** | 건조도 Dryness | 10 |
| **O** | 유분도 Oiliness | 11 |
| **R** | 부위별 차이 Region | 4 |
| **H** | 유분 + 속건조 동시성 | 2 |

**점수표**

| 질문 | ① 선택 시 | ② 선택 시 | ③ 선택 시 |
| --- | --- | --- | --- |
| **Q1. 세안 후 피부 느낌** | `D +2` | `점수 없음` | `O +2` |
| **Q2. 오후 얼굴 유분** | `점수 없음` | `O +1, R +2` | `O +2` |
| **Q3. 볼 부위 상태** | `D +2` | `점수 없음` | `O +2` |
| **Q4. 이마·코(T존) 상태** | `D +1` | `점수 없음` | `O +2` |
| **Q5. 번들거리면서 속당김** | `O +1, D +1, H +2` | `H +1` | `점수 없음` |
| **Q6. 각질·거친 느낌** | `D +2` | `D +1` | `점수 없음` |
| **Q7. 보습 후 피부 상태** | `D +2` | `점수 없음` | `O +2` |
| **Q8. T존과 볼 상태 차이** | `R +2` | `R +1` | `점수 없음` |

# 2. 랭킹 계산 정책

VION의 개인 맞춤형 랭킹은 전체 사용자에게 동일한 인기순 제품을 제공하는 것이 아니라, 사용자의 **피부 타입·피부 고민·나이**와 제품의 성분 및 적합 정보를 비교하여 사용자에게 상대적으로 적합한 제품 후보를 우선적으로 제공하는 것을 목적으로 한다.

MVP에서는 사용자 정보와 제품 정보를 사전에 정의한 규칙에 따라 점수화하고, **총점이 높은 제품부터 랭킹에 노출**한다.

단, 해당 점수는 제품의 의학적 효능이나 절대적인 품질을 의미하지 않으며, **VION 내부의 개인화 랭킹 정렬을 위한 상대적 점수**로만 사용한다

---

- **공통 운영 기준**
    - 랭킹은 `토너`, `크림`, `클렌징폼` 카테고리별로 각각 계산한다.
    - 각 카테고리의 제품 30개를 제외 없이 모두 1~30위로 보여준다.
    - 추천 점수가 낮은 제품도 제외하지 않고 상위 점수 제품 다음에 이어서 노출한다.
    - 모든 조건이 같으면 제품 ID 오름차순으로 임시 정렬한다.
    - 피부 고민은 최소 1개, 최대 3개까지 필수로 선택한다.
    - 피부 고민에서 `없음` 선택지는 제공하지 않는다.

---

## 2-1. 내 피부 종합 랭킹

사용자의 피부 타입, 피부 고민, 나이대를 모두 반영한 개인 맞춤 랭킹이다.

#### 반영 비율

| 평가 항목 | 비율 |
| --- | --- |
| 피부 타입 점수 | 50% |
| 피부 고민 점수 | 30% |
| 나이대 추천 점수 | 20% |

#### 계산식

```
종합 점수 =
(피부 타입 점수 × 0.5)
+ (피부 고민 점수 × 0.3)
+ (나이대 추천 점수 × 0.2)
```

### 2-1-1. 피부 타입 점수

피부 타입 적합도와 해당 피부 타입이 주의해야 하는 성분 정보를 함께 반영한다.

#### 반영 비율

| 평가 항목 | 비율 |
| --- | --- |
| 피부 타입 적합도 | 80% |
| 피부 타입 안전도 | 20% |

#### 계산식

```
피부 타입 점수 =
(피부 타입 적합도 × 0.8)
+ (피부 타입 안전도 × 0.2)
```

#### 피부 타입 적합도

| 적합도 | 점수 |
| --- | --- |
| 적극 추천 | 100 |
| 추천 | 80 |
| 조건부 추천 | 50 |
| 주의 | 20 |

#### 피부 타입 안전도

| 주의 타입 | 안전도 점수 |
| --- | --- |
| 해당 피부 타입 주의 없음 | 100 |
| 주의 수준 1 | 75 |
| 주의 수준 2 | 40 |
| 주의 수준 3 | 0 |

주의 수준은 숫자가 높을수록 주의가 많이 필요한 제품이라는 의미다.

---

### 2-1-2. 피부 고민 점수

사용자가 선택한 피부 고민과 제품의 피부 고민 태그가 얼마나 일치하는지, 관련 성분 구성이 얼마나 강한지를 반영한다.

#### 반영 비율

| 평가 항목 | 비율 |
| --- | --- |
| 피부 고민 일치율 | 60% |
| 피부 고민 적합도 | 40% |

#### 계산식

```
피부 고민 점수 =
(피부 고민 일치율 × 0.6)
+ (피부 고민 적합도 × 0.4)
```

#### 피부 고민 일치율

```
피부 고민 일치율 =
일치한 피부 고민 개수
÷ 사용자가 선택한 피부 고민 개수
× 100
```

피부 고민 적합도가 1 이상이면 해당 피부 고민과 일치한 것으로 계산한다.

#### 피부 고민 적합도

```
피부 고민 적합도 =
선택 고민의 적합도 합계
÷ (선택 고민 개수 × 3)
× 100
```

#### 피부 고민 적합도 기준

| 적합도 | 기준 |
| --- | --- |
| 3 | 해당 고민과 관련된 핵심 성분 구성이 강함 |
| 2 | 주요 성분으로 해당 고민을 명확하게 뒷받침함 |
| 1 | 보조 성분 수준이거나 제형상 효과가 제한적임 |
| 0 | 해당 고민과 관련된 성분이 없음 |

---

### 2-1-3. 나이대 추천 점수

제품 데이터의 `나이대 추천순`에서 사용자 나이대에 해당하는 점수를 가져온다.

| 추천 순위 | 점수 |
| --- | --- |
| 1순위 | 100 |
| 2순위 | 75 |
| 3순위 | 50 |
| 4순위 | 25 |

---

#### 종합 랭킹 동점 정렬

종합 점수가 같으면 다음 기준을 순서대로 비교한다.

```
종합 점수 내림차순
→ 피부 타입 적합도 내림차순
→ 주의 수준 오름차순
→ 피부 고민 일치 개수 내림차순
→ 피부 고민 적합도 합계 내림차순
→ 피부 고민 적합도 3 개수 내림차순
→ 나이대 추천 점수 내림차순
→ 제품 ID 오름차순
```

## 2-2. 내 피부 고민 맞춤 랭킹

사용자가 선택한 피부 고민만 반영하는 랭킹이다.

피부 타입, 주의 타입, 사용감, 나이대는 계산하지 않는다.

#### 반영 비율

| 평가 항목 | 비율 |
| --- | --- |
| 피부 고민 일치율 | 60% |
| 피부 고민 적합도 | 40% |

#### 계산식

```
피부 고민 점수 =
(피부 고민 일치율 × 0.6)
+ (피부 고민 적합도 × 0.4)
```

#### 피부 고민 일치율

```
피부 고민 일치율 =
일치한 피부 고민 개수
÷ 사용자가 선택한 피부 고민 개수
× 100
```

#### 피부 고민 적합도

```
피부 고민 적합도 =
선택 고민의 적합도 합계
÷ (선택 고민 개수 × 3)
× 100
```

#### 동점 정렬

```
피부 고민 점수 내림차순
→ 피부 고민 일치 개수 내림차순
→ 선택 고민 중 최저 적합도 내림차순
→ 피부 고민 적합도 합계 내림차순
→ 피부 고민 적합도 3 개수 내림차순
→ 제품 ID 오름차순
```

#### 계산 예시

사용자가 `보습`, `민감성`을 선택한 경우:

| 제품 | 보습 | 민감성 | 일치 개수 | 최저 적합도 | 적합도 합계 |
| --- | --- | --- | --- | --- | --- |
| 제품 A | 3 | 2 | 2 | 2 | 5 |
| 제품 B | 3 | 1 | 2 | 1 | 4 |
| 제품 C | 3 | 0 | 1 | 0 | 3 |

정렬 결과:

```
제품 A → 제품 B → 제품 C
```

제품 A와 제품 B는 모두 두 가지 고민과 일치하지만, 제품 A의 적합도가 더 높으므로 먼저 노출된다.

## 2-3. 내 피부 타입 추천 랭킹

사용자의 피부 타입 적합도, 해당 피부 타입의 주의 수준, 피부 타입별 우선 사용감을 반영한다.

피부 고민과 나이대는 계산하지 않는다.

#### 계산 방식

내 피부 타입 추천 랭킹은 항목별 점수를 합산하지 않고, 아래 기준을 순서대로 비교하는 우선순위 스택 방식으로 계산한다.

```
피부 타입 적합도 내림차순
→ 해당 피부 타입 주의 수준 오름차순
→ 우선 사용감 태그 일치 개수 내림차순
→ 제품 ID 오름차순
```

### 2-3-1. 피부 타입 적합도

| 적합도 | 정렬 점수 |
| --- | --- |
| 적극 추천 | 100 |
| 추천 | 80 |
| 조건부 추천 | 50 |
| 주의 | 20 |

피부 타입 적합도가 가장 높은 제품을 우선 노출한다.

---

### 2-3-2. 피부 타입 주의 수준

| 주의 타입 | 정렬 값 |
| --- | --- |
| 해당 타입 주의 없음 | 0 |
| 주의 수준 1 | 1 |
| 주의 수준 2 | 2 |
| 주의 수준 3 | 3 |

피부 타입 적합도가 같으면 해당 피부 타입의 주의 수준이 낮은 제품을 먼저 노출한다.

---

### 2-3-3. 피부 타입별 우선 사용감

| 피부 타입 | 우선 사용감 |
| --- | --- |
| 건성 | 촉촉함, 수분감, 보습감 |
| 지성 | 산뜻함, 보송함, 끈적임 적음 |
| 복합성 | 수분감, 산뜻함, 끈적임 적음 |
| 수부지 | 수분감, 가벼움, 빠른 흡수, 끈적임 적음 |
| 중성 | 순한 사용감, 촉촉함, 산뜻함 |

#### 사용감 일치 개수 계산

제품의 `사용감 태그` 중 사용자 피부 타입의 우선 사용감과 일치하는 태그 개수를 계산한다.

```
사용감 일치 개수 =
제품 사용감 태그
∩ 피부 타입별 우선 사용감 태그
```

#### 예시

건성 사용자의 경우:

```
건성 우선 사용감:
촉촉함, 수분감, 보습감

제품 사용감 태그:
촉촉함, 수분감, 빠른 흡수

사용감 일치 개수:
2개
```

피부 타입 적합도와 주의 수준이 같으면 사용감 태그가 더 많이 일치하는 제품을 먼저 노출한다.

#### 정렬 예시

건성 사용자의 제품 정렬:

| 제품 | 건성 적합도 | 건성 주의 | 사용감 일치 | 노출 순위 |
| --- | --- | --- | --- | --- |
| 제품 A | 적극 추천 | 0 | 2개 | 1위 |
| 제품 B | 적극 추천 | 0 | 1개 | 2위 |
| 제품 C | 적극 추천 | 1 | 3개 | 3위 |
| 제품 D | 추천 | 0 | 3개 | 4위 |

제품 C는 사용감 태그가 더 많이 일치하지만 주의 수준이 있으므로 제품 A와 B 다음에 노출한다.

제품 D는 주의가 없더라도 피부 타입 적합도가 `추천`이므로 `적극 추천` 제품보다 뒤에 노출한다.

---

## 2-4. 내 나이대 추천 랭킹

사용자의 나이대 추천 점수를 우선 적용하고, 같은 추천 점수 안에서는 동일 나이대 사용자의 찜 수로 순위를 정한다.

피부 타입, 피부 고민, 주의 타입, 사용감은 반영하지 않는다.

#### 정렬 기준

```
나이대 추천 점수 내림차순
→ 동일 나이대 사용자 찜 수 내림차순
→ 제품 ID 오름차순
```

#### 나이대 추천 점수

| 추천 순위 | 점수 |
| --- | --- |
| 1순위 | 100 |
| 2순위 | 75 |
| 3순위 | 50 |
| 4순위 | 25 |

#### 제품 노출 순서

```
100점 제품 전체
→ 75점 제품 전체
→ 50점 제품 전체
→ 25점 제품 전체
```

100점 제품이 30개 미만이어도 100점 제품만 보여주는 것이 아니라 다음 점수의 제품을 이어서 노출해 총 30위를 구성한다.

같은 점수 구간 안에서는 동일 나이대 사용자의 찜 수가 많은 제품을 먼저 보여준다.

#### 계산 예시

20대 사용자의 크림 랭킹:

| 제품 | 20대 추천 점수 | 20대 찜 수 | 노출 순위 |
| --- | --- | --- | --- |
| 제품 A | 100 | 35 | 1위 |
| 제품 B | 100 | 20 | 2위 |
| 제품 C | 100 | 15 | 3위 |
| 제품 D | 75 | 50 | 4위 |
| 제품 E | 75 | 31 | 5위 |
| 제품 F | 50 | 70 | 6위 |

제품 F의 찜 수가 더 많더라도 나이대 추천 점수가 낮기 때문에 75점 제품보다 먼저 노출되지 않는다.

초기에는 찜 데이터가 없으므로 같은 나이대 추천 점수 안에서 제품 ID 오름차순으로 정렬한다.

## 2-5. 최종 정리

| 랭킹 | 반영 기준 | 계산 방식 |
| --- | --- | --- |
| 내 피부 종합 랭킹 | 피부 타입, 주의 타입, 피부 고민, 나이대 | 피부 타입 50% + 피부 고민 30% + 나이대 20% |
| 내 피부 고민 맞춤 랭킹 | 피부 고민 일치율, 피부 고민 적합도 | 고민 일치율 60% + 고민 적합도 40% |
| 내 피부 타입 추천 랭킹 | 타입 적합도, 주의 수준, 우선 사용감 | 적합도 → 주의 수준 → 사용감 일치 개수 → ID |
| 내 나이대 추천 랭킹 | 나이대 추천 점수, 동일 나이대 찜 수 | 나이대 점수 → 찜 수 → ID |

#### 최종 정렬 공식

```
1. 내 피부 종합 랭킹

종합 점수 DESC
→ 피부 타입 적합도 DESC
→ 주의 수준 ASC
→ 피부 고민 일치 개수 DESC
→ 피부 고민 적합도 합계 DESC
→ 피부 고민 적합도 3 개수 DESC
→ 나이대 추천 점수 DESC
→ 제품 ID ASC
```

```
2. 내 피부 고민 맞춤 랭킹

피부 고민 점수 DESC
→ 피부 고민 일치 개수 DESC
→ 선택 고민 중 최저 적합도 DESC
→ 피부 고민 적합도 합계 DESC
→ 피부 고민 적합도 3 개수 DESC
→ 제품 ID ASC
```

```
3. 내 피부 타입 추천 랭킹

피부 타입 적합도 DESC
→ 해당 타입 주의 수준 ASC
→ 우선 사용감 태그 일치 개수 DESC
→ 제품 ID ASC
```

```
4. 내 나이대 추천 랭킹

나이대 추천 점수 DESC
→ 동일 나이대 사용자 찜 수 DESC
→ 제품 ID ASC
```

# 3. 리뷰 노출 규칙

## 3-1. 용어 정리

| 용어 | 정의 |
| --- | --- |
| Skin_type | 온보딩에서 수집한 **피부타입(단일) + 피부고민(다중)** 조합을 통칭
필드 하나가 아니라 "피부타입 1개 + 피부고민 N개"의 묶음을 의미 |
| 배지 | 리뷰 작성자의 Skin_type을 리뷰 아이디 하단에 노출하는 태그.
피부타입 1개 + 작성자가 선택했던 피부고민 개수만큼 노출(개수는 작성자마다 다름) |
| 조회자 프로필 | "맞춤형 리뷰 노출" 토글을 켠 현재 사용자의 Skin_type(온보딩/마이페이지에서 저장된 값) |

---

## 3-2. 배지 노출 규칙

- 모든 리뷰의 작성자 아이디 하단에 **작성자의 Skin_type을 배지로 노출**한다
(맞춤형 리뷰 토글 ON/OFF와 무관하게 항상 노출).
- 배지 구성 = 피부타입 1개 + 피부고민 N개(작성자가 온보딩에서 선택한 개수만큼).
    
    
    | 작성자 Skin_type | 배지 개수 | 배지 예시 |
    | --- | --- | --- |
    | 건성 + (보습, 모공) | 3개 | `건성` `수분` `모공` |
    | 지성 + (여드름) | 2개 | `지성` `여드름` |

## 3-3. 매칭(필터링) 규칙 : 토글 ON

- **판정 방식:**

**OR 매칭**. 조회자 프로필(피부타입 1개 + 피부고민 N개)과 리뷰 작성자 배지를 비교해, **하나라도 겹치면 "일치"로 간주해 노출**한다.

- 피부타입만 일치해도 노출
- 피부고민만 일치 → 비노출
- 여러 개가 겹쳐도 우선순위·가중치를 두지 않음(4번 정렬 규칙 참고)
- 겹치는 배지가 하나도 없는 리뷰는 노출되지 않음. (단, 토글이 OFF 된 상태에서는 노출됨)

1. 피부 타입 : 무조건 겹쳐야 함
2. 피부 고민 : 1개 이상 중복된다면 노출
- **비교 대상 범위:**
    
    조회자가 온보딩에서 **다중 선택한 피부고민 전체**를 매칭 비교 대상으로 삼는다(일부만 반영하지 않음).
    
- **피부 프로필 수정 시, 반영 시점:**
    
    조회자가 마이페이지에서 피부 타입/고민을 수정하면, **수정 즉시** 변경된 값을 기준으로 리뷰 매칭·배지 비교
    
- **매칭 예시**
    
    > 조회자 프로필: `건성` + `보습`
    > 
    
    | 리뷰 작성자 배지 | 겹치는 배지 | 노출 여부 |
    | --- | --- | --- |
    | 건성, 보습, 여드름 | 건성, 보습 (2개) | ✅ 노출 |
    | 건성, 모공 | 건성 (1개) | ✅ 노출 |
    | 지성, 여드름 | 없음 | ❌ 미노출 |
- **정렬 규칙**
    - 매칭된(일치하는) 리뷰들은 별도의 우선순위 그룹 없이 **최신순으로 정렬**
    - "타입만 일치" / "고민만 일치" / "타입+고민 모두 일치" 리뷰를 구분해서 상단에 배치하지 않고,
    매칭된 리뷰 전체를 하나의 목록으로 합쳐 작성일 기준 최신순으로 노출.
    - 결과가 없는 경우 (기존 스펙 재확인)
        - 조회자 프로필과 겹치는 배지를 가진 리뷰가 하나도 없을 경우,
        "내 피부와 일치하는 리뷰가 없어요" 토스트 + 토글 자동 OFF
    - 토글 OFF 상태 : 전체 리뷰를 최신순으로 정렬하여 노출
